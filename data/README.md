# Data attribution

Lauren Tomanek and Daniel Stutts (2021). *Data on the Validation to Determine the Material Thermal Properties Estimation Via a One-Dimensional Transient Convection Model*, version 1. Missouri University of Science and Technology. [Mendeley Data](https://doi.org/10.17632/sbcf36976g.1) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

This directory reproduces the 27 original temperature acquisition CSVs byte for byte. The file selection, source URLs, and SHA-256 checksums appear in [the manifest](../data_manifest.json). The figures and benchmark outputs resample and use the first 240 seconds of each log. They are derived from these measurements.
